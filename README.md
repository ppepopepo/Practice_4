# BMP Image Processor

Программа для обработки BMP изображений с использованием WinAPI.

## Функции:
- Увеличение яркости
- Псевдо-сепия
- Двухцветное тонирование
- Эффект старого комикса
- Зеркальное отражение по диагонали
- Поворот на 180 градусов
- Пикселизация

## Сборка:
mkdir build
cd build
cmake -S .. -G "Visual Studio 17 2022" -A Win32
cmake --build . --config Release

## Тестирование:
ctest -C Release
